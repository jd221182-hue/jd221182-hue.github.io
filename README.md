# Open Money Calculators

Small, transparent calculators for insurance and money decisions. Plain HTML and JavaScript, no tracking, no build step.

Live site: https://jd221182-hue.github.io/

- Deductible break-even
- Mortgage points break-even
- Should you drop collision coverage?
- Money-weighted return (XIRR)
- Emergency fund (bare-bones month)

General information and math only, not financial, insurance, or tax advice.
